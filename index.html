Module 7 Enterprise Practice Bank

Practice like it is a real job.

51 problems from banks, warehouses, hospitals, HR and e-commerce. Each one uses a Module 7 idea: text files, seek and tell, CSV, JSON, the os module, pathlib, and zip and gzip. Every problem gives you starting data that creates its own dummy files, so nothing is ever missing. Try it in VS Code first, then check yourself against the expected output.

Read and write a file

  1. Which file am I touching, and does it exist?
  2. Which mode: r, w, a? (w EMPTIES the file)
  3. Text or bytes? (r or rb)
  4. Did I use with, so it closes itself?

Understand the data (CSV, JSON)

  • CSV always returns TEXT, so cast numbers
  • JSON keeps real types (numbers, True, None)
  • What can go wrong: bad row, broken JSON?
  • Which except catches exactly that?

Organise and pack (os, pathlib, zip)

  1. Where am I? Print os.getcwd() first
  2. Check it exists before you act
  3. Delete and overwrite have no undo
  4. Zip many files, gzip one file
Stuck? Run print(os.getcwd()) and print(os.listdir(".")) first. Half of all file errors are the wrong folder. Then print what you read before you process it. Open the new file in Notepad after each write to see what really landed on disk.
